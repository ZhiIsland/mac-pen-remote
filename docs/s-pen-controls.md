# S Pen 操作（1.0.1-pen.3）

针对日常远控电脑设计，设置入口为 **设置 → 控制 → S Pen 操作**。

| 操作 | 行为 |
| --- | --- |
| 笔尖点按、拖动，不按侧键 | 保留正常操作；默认指针模式为左键和拖动 |
| 按住侧键，笔尖点按后抬起 | 右键 |
| 按住侧键，笔尖上下或左右拖动 | 垂直、水平滚动 |
| 笔在屏幕悬停感应范围内，原地按下再松开侧键 | 右键 |
| 笔悬停时按住侧键移动 | 垂直、水平滚动 |
| 松开侧键 | 停止滚动；接触中的笔需抬起后才能开始下一次普通拖动 |
| 按住侧键，笔尖轻压 / 重压并移动 | 轻压慢滚、重压快滚 |
| 按住侧键，快速悬停移动 | 根据移动速度加速滚动 |
| 不按侧键，悬停片刻 | 显示 2.5 倍局部放大镜，跟随缓慢移动 |
| 原地悬停按住侧键 0.65 秒 | 默认打开快捷菜单 |
| 悬停双击侧键 | 默认关闭；可在设置中分配动作 |

可以单独关闭悬停操作，调整 0.5 / 1 / 2 倍滚动速度，以及反转滚动方向。关闭“侧键滚动”总开关可恢复原来的接触侧键操作。

## 新增调节与辅助功能

- **压感调速**默认开启：按设备报告的压力范围归一化、平滑调速，基础速度之外约为 0.45–2.25 倍。它只改变手机发出的滚动量，不需要 Mac 识别笔压；没有有效压力范围时使用固定速度。压力不会触发右键。
- **悬停加速**默认开启：按移动速度加速，额外增益最多 2.5 倍。悬停不使用压力值。
- **滚动方向锁**默认开启：主要方向明确后，过滤另一方向的小幅抖动；松键或抬笔开始新手势后重置。需要自由斜向滚动时可关闭。
- **悬停放大镜**默认开启：不按侧键停留约 0.35 秒显示；快速移动、按侧键、落笔、切后台时隐藏。直接复用 GPU 中的远程画面，无需请求额外截图。放大镜带有瞄准标记，并避开键盘占用区域。
- **防掌触**默认开启：笔悬停或接触时取消已有手指操作、忽略新手指输入，离开后保留 150 毫秒保护。被忽略的触摸会一直消费到手指抬起。需要手指配合笔操作时可关闭。
- **快捷操作**：原地悬停长按侧键默认打开菜单，菜单包含右键、中键、键盘、工具栏、调度中心、显示桌面。长按和双击也可直接绑定这些快捷动作。双击默认关闭；启用后，悬停单击会等待 0.3 秒，避免先触发右键再执行双击动作。移动进入滚动时取消快捷动作。
- **连接切换保护**：切窗口、取消输入、断开和替换连接时取消延迟操作；旧连接的菜单和延迟回调不能操作新连接。

## 手机端传感器测试

进入 **设置 → 控制 → 测试笔传感器**，在方格区域悬停、落笔、改变力度和倾角、按侧键。页面会显示设备名称、压力、倾角、方向、悬停距离和侧键状态，不向 Mac 发送任何操作。

倾角和距离需要在你的 S25 Ultra 上看到实际数值变化后，才能确认可用于控制。距离使用设备自定单位，不是毫米。本版只检测这些轴，不让它们触发远控动作；数据只保存在内存中。

抖动不会立即开始滚动；开始滚动后再移回原点也不会变成右键。悬停滚动后保持同一次按键落笔，不会额外打开右键菜单。离开悬停范围、切换窗口、进入后台或取消触摸时，待触发的右键会取消。

如果三星抢走侧键并弹出浮窗指令，请关闭系统 S Pen 设置中的“使用 S Pen 按钮打开浮窗指令”，实际名称以 One UI 为准。

## S25 Ultra 的硬件边界

三星官方说明：S25 Ultra 的 S Pen 没有蓝牙/BLE，也不支持 Air Actions。因此，**靠近屏幕悬停操作**可以通过 Android 笔事件适配，**远离屏幕按侧键和挥笔**没有可供本 App 接收的硬件数据，无法通过软件开启。

- [Samsung: S25 Ultra S Pen](https://www.samsung.com/us/support/answer/ANS10004602/)
- [Samsung: Air Actions 支持范围](https://www.samsung.com/us/support/troubleshoot/TSG10003504/)

本版本已通过 44 项单元测试、APK 编译、lint 和 Spotless。尚未连接三星真机，One UI 是否把悬停侧键事件交给 App、实际滚动手感和 GPU 放大镜显示效果仍需在手机验证。

建议安装后依次检查：传感器测试页、轻压和重压滚动、悬停侧键单击右键、悬停上下滚动、悬停滚动后落笔、接触侧键点按、接触侧键滚动中松键、悬停放大镜、掌触抑制、长按快捷菜单、启用后的侧键双击、按住侧键时切后台再返回。无三星设备时，构建和状态机测试不能代替这些真机操作。

## 与 Mac 原生触控的关系

本版本的右键和滚动通过普通 VNC 或苹果扩展协议发送，不要求 macOS 27.3。Mac 原生触控是另一项能力：

- `internal/rfb/touch.go` 的 `TouchAvailable()` 检查服务端是否声明接受苹果 HID 报告（消息 `0x26`），不是仅比较系统版本。
- 连接不能是仅观察模式，显示布局必须存在，且当前会话需要处于本机控制台桌面。
- Android 收到 `supportsTouch` 后才提供“原生触控”开关；开关开启且会话可控制时才实际发送触控。
- 源码中的 27.3 注释记录了作者分析的系统版本，不能据此保证所有旧版本或所有 27.3 会话可用。手工放开界面开关不会补上 Mac 端缺少的协议实现。

如果开启了 Mac 原生触控，不按侧键的笔尖输入仍遵循上游的原生触控路径。笔的悬停侧键与接触侧键滚动则由本分支处理。
