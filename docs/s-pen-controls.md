# S Pen 操作（1.0.1-pen.2）

针对日常远控电脑设计，设置入口为 **设置 → 控制 → S Pen 操作**。

| 操作 | 行为 |
| --- | --- |
| 笔尖点按、拖动，不按侧键 | 保留正常操作；默认指针模式为左键和拖动 |
| 按住侧键，笔尖点按后抬起 | 右键 |
| 按住侧键，笔尖上下或左右拖动 | 垂直、水平滚动 |
| 笔在屏幕悬停感应范围内，原地按下再松开侧键 | 右键 |
| 笔悬停时按住侧键移动 | 垂直、水平滚动 |
| 松开侧键 | 停止滚动；接触中的笔需抬起后才能开始下一次普通拖动 |

可以单独关闭悬停操作，调整 0.5 / 1 / 2 倍滚动速度，以及反转滚动方向。关闭“侧键滚动”总开关可恢复原来的接触侧键操作。

抖动不会立即开始滚动；开始滚动后再移回原点也不会变成右键。悬停滚动后保持同一次按键落笔，不会额外打开右键菜单。离开悬停范围、切换窗口、进入后台或取消触摸时，待触发的右键会取消。

如果三星抢走侧键并弹出浮窗指令，请关闭系统 S Pen 设置中的“使用 S Pen 按钮打开浮窗指令”，实际名称以 One UI 为准。

## S25 Ultra 的硬件边界

三星官方说明：S25 Ultra 的 S Pen 没有蓝牙/BLE，也不支持 Air Actions。因此，**靠近屏幕悬停操作**可以通过 Android 笔事件适配，**远离屏幕按侧键和挥笔**没有可供本 App 接收的硬件数据，无法通过软件开启。

- [Samsung: S25 Ultra S Pen](https://www.samsung.com/us/support/answer/ANS10004602/)
- [Samsung: Air Actions 支持范围](https://www.samsung.com/us/support/troubleshoot/TSG10003504/)

本版本已通过 19 项单元测试、APK 编译、lint 和 Spotless。尚未连接三星真机，One UI 是否把悬停侧键事件交给 App、实际滚动手感仍需在手机验证。

建议安装后依次检查：悬停侧键单击右键、悬停上下滚动、悬停滚动后落笔、接触侧键点按、接触侧键滚动中松键、按住侧键时切后台再返回。无三星设备时，构建和状态机测试不能代替这些真机操作。

## 与 Mac 原生触控的关系

本版本的右键和滚动通过普通 VNC 或苹果扩展协议发送，不要求 macOS 27.3。Mac 原生触控是另一项能力：

- `internal/rfb/touch.go` 的 `TouchAvailable()` 检查服务端是否声明接受苹果 HID 报告（消息 `0x26`），不是仅比较系统版本。
- 连接不能是仅观察模式，显示布局必须存在，且当前会话需要处于本机控制台桌面。
- Android 收到 `supportsTouch` 后才提供“原生触控”开关；开关开启且会话可控制时才实际发送触控。
- 源码中的 27.3 注释记录了作者分析的系统版本，不能据此保证所有旧版本或所有 27.3 会话可用。手工放开界面开关不会补上 Mac 端缺少的协议实现。

如果开启了 Mac 原生触控，不按侧键的笔尖输入仍遵循上游的原生触控路径。笔的悬停侧键与接触侧键滚动则由本分支处理。
