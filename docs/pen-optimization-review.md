# 笔操作优化复查

## 本次已实现

| 需求或发现 | 处理 |
| --- | --- |
| 轻微滚动和快速翻页切换不方便 | 接触时压感调速；悬停时按移动速度加速；可单独关闭 |
| 垂直滚动时横向抖动 | 可关闭的主要方向锁，每次手势重置 |
| 手机点 Mac 小按钮困难 | 停留后显示带瞄准标记的局部 GPU 放大镜，缓慢移动时跟随 |
| 笔靠近时手掌引起误点或拖动 | 取消已有手指手势、抑制新手指触摸，并消费到该手指抬起 |
| 常用键盘、工具栏、桌面动作入口较远 | 悬停长按快捷菜单；长按和双击可配置直接动作 |
| 双击动作同时触发右键 | 可选的单击等待窗口；默认关闭双击，不增加默认右键延迟 |
| 传感器 API 存在但设备未必提供有效数据 | 独立本地检测页；倾角和距离暂不绑定远控动作 |
| 切后台或重连后延迟任务仍可能执行 | 取消任务并校验连接代次；菜单操作同样校验 |
| 悬停数据更新频率高 | 远控中的传感器读数限频；放大镜复用 GPU 画面，不做逐帧 CPU 截图 |

## 复查后仍需真机证据的项目

- **个人力度曲线**：当前使用设备的标准压力范围和保守的平滑曲线。需先看 S25 Ultra 实际轻压、常用力度、重压的读数，再判断是否需要增加个人校准或更多曲线档位。
- **倾角切换滚动方向**：当前横纵移动和方向锁已经提供确定的操作方式。应先确认 S25 Ultra 的倾角、方向是否连续稳定，再增加可选映射，避免正常握笔改变滚动方向。
- **悬停距离控制速度**：有些驱动没有此轴，或者只有固定值；检测页可识别。只有实际值连续变化且手感稳定时才值得增加。
- **精细点击和放大镜摆位**：几何测试覆盖边角、横屏、键盘区域和原有遮挡放大镜，但尚未验证 S25 Ultra 的 GPU 显示和笔尖遮挡，应以手机体验决定尺寸、停留时间和位置的下一轮调整。

不把缺少 BLE 的 S25 Ultra 远距离侧键、挥笔或笔内陀螺仪列入软件可实现功能。Mac 绘图压感透传需要另一个服务端输入通道，本次实现的是手机端把压力转换为常规滚动。

## 验证边界

44 项 JVM 单元测试覆盖按键与悬停转换、取消、压感归一化与平滑、速度与密度、横纵锁、掌触保护时序、双击仲裁、放大镜裁剪和坐标变换，以及已有首帧回退逻辑。APK 编译、lint 和 Spotless 通过。未连接 Android / 三星设备，也未安装或运行模拟器，因此没有宣称实际手机交互或 OpenGL 显示验证完成。
