# 操控增强（1.0.1-pen.4）

## 新增功能

1. **自定义笔快捷菜单**：设置 → 控制 → 自定义笔快捷菜单，可勾选、排序、恢复默认。增加复制、粘贴、剪切、撤销、重做、全选、查找、切换应用、Esc、拖拽锁定、鼠标面板和手指模式。选择“快捷输入”可执行或编辑已有的自定义文本/按键序列。
2. **拖拽锁定**：在目标处打开笔菜单，选择“开始锁定拖拽”，或使用工具栏控制菜单/鼠标面板的对应按钮。左键保持按下，抬笔或抬手后可继续移动。点面板的“结束拖拽”或左键按钮释放；普通手指轻点也可结束。开始锁定时会自动显示面板。
3. **单手鼠标面板**：工具栏的鼠标入口、控制菜单、笔菜单或设置中打开。中间区域滑动相对移动，轻点单击；右侧滚动区上下滑动。下方提供左、右、中键、拖拽锁定和手指模式。拖动标题栏改变位置，位置按屏幕可用区域比例保存。关闭按钮同时结束锁定拖拽。软键盘显示时面板收起。
4. **手指直点/触摸板切换**：直接定位时轻点在手指位置单击，长按拖拽；触摸板保持原来的相对移动。笔不受该设置影响。通过面板、笔菜单、工具栏控制菜单或设置切换。明确选择此模式会关闭原生触控，普通 VNC 即可使用。
5. **指针速度和加速度**：设置 → 控制，速度可选 50%、75%、100%、150%、200%，加速度可关闭。仅影响手指触摸板和面板的相对移动；默认 100% 加速保留旧曲线，笔的直接定位和侧键滚动不变。

## 保护规则

- 断线/重连、失去控制权、切后台、窗口失焦、视图释放时清除拖拽锁定。关闭鼠标面板、切换手指模式也会释放。
- 开始锁定拖拽时关闭原生触控，使用普通鼠标输入。
- 笔菜单仍校验原会话代次；已断开的旧菜单不能对新会话发输入。
- 鼠标面板手势以会话代次为界，滚动取消时发送结束/取消，避免旧手势延续到新连接。
- 自动弹出键盘与远端焦点猜测没有实现。

## 真机验收

在 S25 Ultra 上覆盖更新后，优先验证：菜单排序持久化；中文复制/粘贴与自定义组合键；锁定后抬笔继续拖动与显式结束；按住拖拽切后台/断线；面板拖动、横屏及分屏边界；面板滚动后取消；两种手指模式与侧键滚动互不干扰。

构建与状态逻辑测试不能代替手机上的输入分发、面板显示和实际拖拽体验。
